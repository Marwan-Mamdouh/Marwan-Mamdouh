## Featured Projects

### [IEEE Al-Azhar Board API](https://github.com/Marwan-Mamdouh/ieee-board-api) · [Live Docs](https://ieee-alazhar-api.vercel.app/api/docs)

> Production REST API serving the IEEE Al-Azhar student branch website

- Event-driven cache invalidation with typed Node.js EventEmitter — no message broker needed
- Zod discriminated union validation enforcing cross-field business rules at the schema layer
- HTTP caching with ETag generation and 304 short-circuit responses
- Cloudinary image pipeline with orphan-prevention cleanup logic
- Auto-generated OpenAPI docs from Zod schemas via `zod-to-openapi`

---

### [EcoSphere](https://github.com/Marwan-Mamdouh/EcoSphere) · [Live Demo](https://eco-sphere-kappa.vercel.app/en)

> Multi-role waste management platform with payment integration

- 5 distinct user roles with no conditional role-checking — clean strategy-based design
- Stripe webhook handling for real-time subscription event consistency
- Layered backend architecture (controller → service → repository)
- GitHub Actions CI/CD pipeline for automated build and deployment validation
